
This project explores how Large Language Models (LLMs), specifically Gemini 1.5 Flash, can be integrated into a data science workflow using the Titanic dataset for the following tools:
* SQL 
* ML 
* Programmatic Prompting

Key answers that were studied or answered using Prompt Engineering based on the Project problem statement are:-

* SQL Query Generation & Interpretation using LLM prompts.

* Feature Engineering in Pandas suggested and applied via programmatic prompting.

* ML Model Recommendations with hyperparameter tuning, training, and evaluation.

* Automated Reporting generated directly with LLM assistance.

* Prompt Engineering Notebook (Prompt_Engineering.ipynb) showcasing practical experiments in SQL, preprocessing, ML, and reporting.
